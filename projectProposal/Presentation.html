01 . Platform Concept

The Vision: All-Around Customizability

Traditional AgriTech hardware is fixed and single-purpose. This platform breaks this constraint by proposing a modular, scalable, and plug-and-play architecture:

1. Configurable Sensing Core

A single sensor board design equipped with breakout channels (I2C, 1-Wire, and Analog ADC). Swap from air climate monitoring (SHT31) to water acidity (pH) or air purity/safety gases (MQ135) without changing the core motherboard.

2. Stackable Relay Expansion

Actuator nodes scale seamlessly. Start with a single fan relay and expand to 8 stacked relay channels (via I2C expanders) to automate heating, cooling, misting, watering, and feeding loops.

02 . Master Node

Gateway Hub (SIM800L GPRS)

The central database bridge that coordinates local node logic and syncs data to the cloud when internet is available.

Core Gateway BOM

  • ESP32 Microcontroller: Dual-core FreeRTOS coordinator.
  • SIM800L GPRS: Dedicated cellular data backhaul.
  • LM2596 Converter + 1000µF Cap: Handles GSM power surges.
  • SSD1306 OLED Screen: Local network health diagnostics.

Gateway Core Responsibilities

  • LittleFS Circular Buffer: Automatically caches sensor streams in local flash when GPRS fails, uploading them chronologically when online.
  • NTP/Network Time Sync: Pulls cell time to sync sleeping nodes.
  • Direct Override Rules Engine: Coordinates cross-node inputs locally.
03 . Sensor Node Blueprint

Configurable & Editable Sensor Node

The child sensor node is an editable board. It configures automatically based on what sensors are attached:

Baseline Setup: Climate (SHT31)

  • SHT31-D (I2C): Condensation-proof Temp & Humidity.
  • P-MOSFET Power Gating: Completely cuts VCC lines during sleep, dropping node quiescent current to **<15µA** for a 2-year battery life.

Plug-and-Play Expansion Kits

  • Water/Soil pH Kit: Optional pH-4502C analog probe with 10k/20k voltage divider to scale output to the 3.3V ESP32 ADC.
  • Temperature Compensation: Optional DS18B20 1-Wire probe to adjust the pH slope for solution temperature changes.
04 . Actuator Node Blueprint

Expandable Multi-Relay Controller

Designed to scale up or down depending on the size of the greenhouse or barn utilities:

Stackable Relay Bus

By utilizing an I2C GPIO Expander (e.g. **PCF8574**), the node can trigger up to **8 relays** using only 2 pins on the ESP32, keeping GPIO pins free for diagnostics or flow meters.

  • 5V Relays: Optocoupler-isolated (10A @ 250V AC).
  • Mains Supply: Board-mounted HLK-PM01 AC-DC module.

Industrial Safety Protection

  • RC Snubber Circuits: Wired across AC relay contacts to absorb voltage arcs and prevent electromagnetic interference from hanging the MCU.
  • Hearbeat Safe-State: Automatically turns off pumps/valves if the Master heartbeat signal drops.
05 . Network Infrastructure

Self-Describing Mesh Protocol

Because child nodes are editable and custom, the communication framework is designed to adapt dynamically:

Self-Describing Headers

Each child node transmits a structured packet containing a **configuration header byte** (e.g. `0x01` = SHT31 only, `0x03` = SHT31 + pH + Temp). The Master receives this header, decodes it on the fly, and saves the data without requiring firmware changes.

Decoupled Local Inter-Comm

Nodes communicate locally without requiring the internet. A sensor node can directly command a neighboring relay node (e.g., "Air humidity is 30% -> turn on misting pump") even if the Master gateway is completely offline.
